# A little hello

Open `index.html` directly. No setup or backend is needed.

- **Reply via Gmail:** opens a draft to ganeshsenthil157@gmail.com with the selected answer and optional Instagram input.
- **Message me on LinkedIn:** opens https://www.linkedin.com/in/ganesh-s-34874924b/ so the visitor can message you there. They type or paste their Instagram in that message.

Nothing is automatically sent, saved, downloaded or tracked. The visitor sends the message themselves. Gmail or LinkedIn may ask them to sign in.

To publish, upload the ZIP contents to your GitHub repo. Under Settings > Pages, choose Deploy from a branch, then main and / (root). Private-repo GitHub Pages requires an eligible paid GitHub plan.

The email address and LinkedIn link can be changed in `site.config.js`.
